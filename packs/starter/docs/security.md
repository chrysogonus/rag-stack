# Security

## Passwords

Keep every password in the company password manager, and use a different password for each account.

## Two-factor authentication

Turn on two-factor authentication for email, chat and the code host. Use the authenticator app, not text messages.

## Phishing

Forward a suspicious email to security@example.org, then delete it. Never enter your password on a page you reached from a link in an email.

## Lost or stolen devices

Report a lost or stolen laptop or phone to the IT desk within one hour. The IT desk locks and wipes it remotely.
